{% if mapping_language == 'zh' %}切空间之间的局部转换{% else %}Local tangent conversion{% endif %} \(\displaystyle\frac{-F^{\mathcal N}}{2(n-1)}\circledast\frac{\partial d_s}{\partial\mathcal C_s}\)
\(\displaystyle d=\operatorname{adj}(\mathcal C)\)
\[\begin{aligned} \text{SDE:}\quad \mathrm d\mathcal C_t &\approx\left[\mathbf f(\mathcal C_t,t)-\frac{g^2(t)}{2(n-1)} S_t(d_t)\circledast\frac{\partial d_t}{\partial\mathcal C_t}\right]\mathrm dt +\mathbf G(\mathcal C_t,t)\,\mathrm d\overline W_t,\\[0.6em] \text{VE ODE:}\quad\frac{\mathrm d\mathcal C_t}{\mathrm dt} &\approx\frac{G^2(t)}{2(n-1)}\left[\frac{3}{d_t}-S_t(d_t)\right] \circledast\frac{\partial d_t}{\partial\mathcal C_t},\\[0.6em] \text{VE ODE (practical):}\quad\frac{\mathrm d\mathcal C_t}{\mathrm dt} &\approx-\frac{G^2(t)}{2(n-1)}S_t(d_t)\circledast\frac{\partial d_t}{\partial\mathcal C_t}. \end{aligned}\]

{% if mapping_language == 'zh' %}沿 \(t:T\to0\) 逆向积分。\(S_t=\nabla_d\log p_t\) 为距离 score；\(\mathbf f,\mathbf G\) 为坐标侧漂移与噪声系数，\(g\) 为距离侧噪声系数，\(\overline W_t\) 为逆时间 Brownian motion。\(n\) 为点数，\(\circledast\) 按边汇总坐标位移。{% else %}Integrate backward along \(t:T\to0\). \(S_t=\nabla_d\log p_t\) is the distance score. \(\mathbf f,\mathbf G\) are the coordinate drift and noise coefficient; \(g\) is the distance noise coefficient; \(\overline W_t\) is reverse-time Brownian motion. \(n\) counts points; \(\circledast\) aggregates edge contributions to coordinates.{% endif %}

{% if mapping_language == 'zh' %}ODE 适用 VE：\(\mathbf f=0\)、\(\mathbf G=G(t)I\)、\(g=\sqrt2\,G\)；\(3/d_t\) 按元素相除。实用式采用高斯距离 score 并省略径向漂移。以上均使用局部沿边近似，忽略距离条目间的相关性。SDE 推导 · ODE 条件。{% else %}The ODE assumes VE: \(\mathbf f=0\), \(\mathbf G=G(t)I\), \(g=\sqrt2\,G\); division in \(3/d_t\) is entrywise. The practical form uses a Gaussian distance score and omits radial drift. These local edge approximations ignore correlations between distance entries. SDE derivation · ODE assumptions.{% endif %}

\[\begin{aligned} \mathcal C^{k-1}&=\mathcal C^k- \frac{F^{\mathcal N}(d^k,s)}{2(n-1)}\circledast\frac{\partial d^k}{\partial\mathcal C^k},\\[0.6em] F^{\mathcal N}(d^k,s)&=\tau\bigl[f(d^k,s)-g^2(s)S_s(d^k)\bigr] +\sqrt\tau\,g(s)\,z^{s,d^k},\\[0.4em] \tau&=T/K,\qquad s=k\tau,\qquad t=(k-1)\tau=s-\tau. \end{aligned}\]

{% if mapping_language == 'zh' %}\(\mathcal C_s=\mathcal C^k\)、\(\mathcal C_t=\mathcal C^{k-1}\)，\(d^k=\operatorname{adj}(\mathcal C^k)\)；\(K\) 为采样总步数，\(n\) 为点数。\(f,g\) 为距离侧漂移和噪声系数，\(S_s=\nabla_d\log p_s\) 为模型估计的距离 score，\(z^{s,d^k}\) 为 \(T_{d^k}M\) 中的标准高斯噪声。{% else %}\(\mathcal C_s=\mathcal C^k\), \(\mathcal C_t=\mathcal C^{k-1}\), and \(d^k=\operatorname{adj}(\mathcal C^k)\). \(K\) counts sampling steps; \(n\) counts points. \(f,g\) are the distance drift and noise coefficient, \(S_s=\nabla_d\log p_s\) is the model's distance score, and \(z^{s,d^k}\) is standard Gaussian noise in \(T_{d^k}M\).{% endif %}

{% if mapping_language == 'zh' %}\(-F^{\mathcal N}\) 合并漂移、score 与随机项；\(\circledast\) 沿各边的 \(\partial d_{ij}/\partial\mathcal C\) 汇总位移。\(1/[2(n-1)]\) 为完整图的局部线性近似系数，Shift 将所得坐标更新施加到 \(L\) 中。{% else %}\(-F^{\mathcal N}\) combines drift, score, and noise. \(\circledast\) sums displacements along the edge derivatives \(\partial d_{ij}/\partial\mathcal C\). The complete-graph factor \(1/[2(n-1)]\) gives a local linear approximation; Shift applies the resulting coordinate update in \(L\).{% endif %}

{% if mapping_language == 'zh' %}当前小步：读取距离 → 预测距离切向量 → 转换到坐标切空间 → Shift 更新坐标。{% else %}Current step: read distances → predict a distance tangent vector → map to the coordinate tangent space → Shift the coordinates.{% endif %}

  1. {% if mapping_language == 'zh' %}当前结构为 \(\mathcal C_s\in L\)，对应距离 \(d_s=\operatorname{adj}(\mathcal C_s)\in M\)。模型以 \(d_s\) 与时间 \(s\) 为输入；\(N\) 中的代表 \(\varphi(d_s)\) 与 \(\mathcal C_s\) 描述相同的距离。{% else %}The current structure \(\mathcal C_s\in L\) has distances \(d_s=\operatorname{adj}(\mathcal C_s)\in M\). The model takes \(d_s\) and time \(s\) as inputs. Its representative \(\varphi(d_s)\in N\) describes the same distances as \(\mathcal C_s\).{% endif %}

  2. {% if mapping_language == 'zh' %}记本小步的距离变化为 \(v_M=-F^{\mathcal N}(d_s,s)\)。橙色箭头从 \(d_s\) 出发，表示理论切空间 \(T_{d_s}M\) 中的更新方向。实际网络输出边上的标量信号，未显式约束为严格的切向量。{% else %}Write the distance change for this step as \(v_M=-F^{\mathcal N}(d_s,s)\). The orange arrow starts at \(d_s\) and illustrates the update in the theoretical tangent space \(T_{d_s}M\). The network outputs scalar edge signals without an explicit constraint enforcing exact tangency.{% endif %}

  3. {% if mapping_language == 'zh' %}在局部光滑选规下，\(\varphi\circ\pi_M\) 的微分把距离方向送入 \(T_{\varphi(d_s)}N\)。论文用沿边方向的线性公式近似这一步，并在当前坐标代表中计算位移 \(\Delta\mathcal C_s\)：{% else %}In a locally smooth gauge, the differential of \(\varphi\circ\pi_M\) carries the distance direction into \(T_{\varphi(d_s)}N\). The paper approximates this step with a linear edge-direction formula, evaluating the displacement \(\Delta\mathcal C_s\) in the current coordinate representative:{% endif %}

    \[\begin{aligned} v_N&=D(\varphi\circ\pi_{M,d_s})_{d_s}[v_M],\\ \Delta\mathcal C_s=A_sv_M &\equiv\frac{-F^{\mathcal N}(d_s,s)}{2(n-1)}\circledast\frac{\partial d_s}{\partial\mathcal C_s}. \end{aligned}\]

    {% if mapping_language == 'zh' %}上式的 \(v_N\) 表示理想切向量；\(A_sv_M\) 是同一小步在普通坐标中的局部近似位移。系数对应完整图，\(\circledast\) 将各边信号汇总为各点位移。{% else %}\(v_N\) denotes the ideal tangent vector; \(A_sv_M\) is the local approximation to that step in ordinary coordinates. The coefficient is for a complete graph, and \(\circledast\) aggregates edge signals into point displacements.{% endif %}

  4. {% if mapping_language == 'zh' %}红色箭头把当前小步落实为 \(L\) 中各点的位移。图中的 Shift 表示在当前嵌入代表上施加该更新，再由新坐标计算下一步的距离：{% else %}The red arrow applies this step as point displacements in \(L\). Shift denotes applying the update to the current embedding representative, then computing the next distances from the updated coordinates:{% endif %}

    \[\begin{aligned} \mathcal C_t&=\operatorname{Shift}(\mathcal C_s,\Delta\mathcal C_s) =\mathcal C_s+\Delta\mathcal C_s,\qquad t<s,\\ d_t&=\operatorname{adj}(\mathcal C_t)\in M. \end{aligned}\]

    {% if mapping_language == 'zh' %}这就完成了一个逆向小步。重复同样的循环，三个空间中的对应点沿各自曲线同步前进，直到 \(\mathcal C_0\)。{% else %}This completes one reverse step. Repeating the loop advances corresponding points along all three trajectories until \(\mathcal C_0\).{% endif %}
