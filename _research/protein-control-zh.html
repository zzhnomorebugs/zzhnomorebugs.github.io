Property-driven protein design

01 给定目标性质，生成值得验证的序列

蛋白质工程希望找到具有目标功能的氨基酸序列。可控生成把目标性质直接交给生成模型，让候选提出过程具有明确方向。

  1. 输入：参考序列与目标性质参考序列提供序列上下文，目标条件描述希望达到的性质。
  2. 生成：带条件的逐步更新在序列先验的约束下，逐步调整氨基酸类别的预测。
  3. 输出：候选变体通过独立评估筛选，供后续实验验证。

生成模型需要同时处理两类要求：序列本身应当合理，生成结果也应当响应目标条件。相对于参考序列提出变体时，还需要关注编辑幅度，避免为了追求目标性质而破坏原有序列与结构。

项目的核心问题

通用蛋白质序列先验，能否为不同性质任务提供可复用的生成基础，并通过条件适配提出具有目标倾向的候选？

目标条件表达什么？

条件可以表达变异效应、稳定性变化或结合性质。模型学习目标条件与序列变化之间的关系，而不同任务仍需要各自的标签定义和评估方法。

输出意味着什么？

输出是需要进一步验证的候选序列。模型预测的性质、结构预测的置信度和真实实验效果分别提供不同层次的证据。

Dividing the work between a general prior and task conditions

02 先学习序列规律，再学习目标条件

天然蛋白质序列提供广泛的统计规律，参考序列提供相对编辑的条件，性质标签则描述任务方向。这几类信息共同参与候选序列的生成。

直接训练一个条件生成器，需要同时学习序列规律与性质条件的影响。本项目把这两项职责显式分开，也让两类数据各司其职：无条件生成预训练可以使用 UniRef90 等大规模蛋白质序列集，学习通用序列规律；下游再冻结先验，只在较小的带性质标签任务集上训练条件引导，也就是残差模型。无条件阶段不要求每条序列都配有下游性质标签，性质标签则用于学习任务特定的修正。整个流程分为三个阶段：

  1. 预训练：学会序列规律用大规模蛋白质序列集学习从带噪状态预测干净 token，得到可复用的通用生成先验。
  2. 条件训练：学会修正预测冻结先验，在较小的带性质标签任务集上，用组合预测的损失训练条件残差。
  3. 条件生成：反复预测与更新固定两路模型，在给定条件下逐步更新生成状态，最终得到候选序列。

对于以参考序列为条件的编辑任务，可以把目标概括为学习条件分布：

\[p_\theta(x\mid x_{\mathrm{ref}},y).\]

其中，\(x_{\mathrm{ref}}\) 是参考序列，\(y\) 是目标性质，\(x\) 是候选序列。这一写法表达任务目标，不意味着模型已经保证每个候选都满足条件。

From conditional score decomposition to residual prediction

03 把条件生成拆成：先验预测、残差修正与状态更新

每一步生成都先回答“当前各位点可能是什么氨基酸”，再依据目标条件调整这些预测。下面依次说明两路模型看什么、输出如何合并、残差怎样学到，以及预测怎样进入生成循环。

分工的动机：条件 score = 无条件 score + 条件修正

对连续带噪变量 \(x_t\)，由贝叶斯公式取对数并对 \(x_t\) 求梯度，可把条件 score 写成下式。这里暂用 \(y\) 表示条件，用于解释分解直觉：

\[\underbrace{s_{\mathrm{c}}}_{\text{conditional score}} =\underbrace{s_{\mathrm{u}}}_{\text{unconditional score}} +\underbrace{\nabla_{x_t}\log p_t(y\mid x_t)}_{\text{条件修正}}.\]

把这一分解落实到模型设计，就是将两个网络的预测输出相加，并把“大数据学先验、小数据学引导”的职责分开。前一项由通用先验网络提供，可利用 UniRef90 这类大规模序列集做无条件生成预训练，在下游训练时冻结参数；后一项由条件残差网络提供，只在较小的带性质标签任务集上训练，结合当前状态、参考序列与目标性质，学习需要补充的修正。训练损失作用于相加后的预测，只更新后一个残差网络；前一个先验网络仍参与每一步预测，但权重不变。

这种分工借鉴了 CFG 的条件控制直觉。上面的连续 score 分解提供设计动机；本项目实际相加的是两个网络输出的离散 token logits，并不把 logits 残差等同于连续 score 或分类器梯度。

3.1 两路模型读取同一状态，承担不同职责

用 \(s_t\) 统一表示生成时刻 \(t\) 的当前状态。对于 BFN，它是每个位点的类别概率信念；对于 DFM，它是带噪的离散 token 序列。\(s_t\) 是正在更新的对象，参考序列 \(x_{\mathrm{ref}}\) 和目标性质 \(y\) 则是本次生成的条件。

通用先验：给出基础预测

读取 \(s_t\) 与时间 \(t\)，输出 \(\ell_{\mathrm{prior}}\)：在当前信息下，每个位点各氨基酸类别的基础分数。下游训练固定它的权重，以复用预训练学到的序列规律。

条件残差：给出预测修正

读取相同的 \(s_t,t\)，并结合 \(x_{\mathrm{ref}},y\)，输出 \(r_\phi\)：针对各位点、各类别的分数修正。参考序列提供相对编辑的上下文，目标性质指定调整方向。

3.2 在 logits 上相加，再变成干净 token 概率

logits 是归一化之前的类别分数。对长度为 \(L\)、类别数为 \(K\) 的序列，两路输出都可看作 \(L\times K\) 的分数表；先在对应元素上相加，再对每个位点的类别维度做 softmax：

\[\begin{aligned} \ell_{\mathrm{cond}}&=\operatorname{stopgrad}\!\left(\ell_{\mathrm{prior}}(s_t,t)\right) +r_\phi(s_t,t,x_{\mathrm{ref}},y),\\ q_i(k)&=\operatorname{softmax}(\ell_{\mathrm{cond},i})_k. \end{aligned}\]

其中 \(i\) 表示位点，\(k\) 表示氨基酸类别。\(q_i(k)\) 是模型对该位点干净 token 的预测概率；它还需要交给生成规则，才会决定下一步如何更新状态。逐位点归一化也不意味着忽略位点之间的关系：两路预测都利用序列上下文。

残差具体“修正”了什么？

用抽象类别 \(\alpha,\beta\) 举例：先验可能更偏好 \(\alpha\)，而当前条件需要提高 \(\beta\) 的相对倾向，残差便可以提高 \(\beta\) 相对于其他类别的分数。softmax 将修正后的分数重新归一化。残差为零时，预测退回通用先验；残差本身既不是概率，也不是一条已经选定的突变指令。

3.3 用组合预测训练，只让残差模型学习

先验完成预训练后，下游只训练条件残差。这里使用的是较小的任务数据集：真实序列配有参考上下文与性质标签，学习信号集中在目标条件所需的修正上。一次训练可以按以下顺序理解：

  1. 构造训练输入。以真实序列 \(x\) 为干净目标，采样时间 \(t\)，按所用框架构造对应的带噪状态 \(s_t\)；同时提供参考序列与该训练样本对应的性质条件。
  2. 计算两路输出。冻结的先验提供基础 logits，残差模型结合状态与条件给出修正，两者按图 2 合成预测 \(q\)。
  3. 用真实序列监督组合结果。沿用对应 BFN / DFM 框架的生成训练目标，让组合预测学习恢复干净序列。两种框架的具体损失不同，但条件适配都作用于组合预测。
  4. 只更新残差参数 \(\phi\)。\(\operatorname{stopgrad}\) 表示下游损失不通过先验分支更新其权重。残差通过“加上修正后，整体预测是否更好”得到学习信号。

因此，训练数据不需要额外提供一份“正确残差”标签；残差从组合预测的训练目标中学到条件修正。性质条件负责告诉模型应恢复哪类序列，性质控制是否有效则要在生成候选后单独评估。

3.4 固定模型，反复执行预测与状态更新

生成时给定参考序列和希望达到的性质，不再提供待恢复的真实目标序列。两路模型都固定权重，按“初始化 → 两路预测 → 合成分布 → 更新状态”的循环提出候选：

  1. 初始化生成状态。起点由所选路径决定。以下一章介绍的基础路径为例，BFN 从均匀类别概率信念开始，DFM-abs 从掩码 token 开始，DFM-uni 从均匀随机 token 开始。参考序列提供相对编辑的条件，需与当前生成状态区分。
  2. 预测、修正、更新。在当前 \(s_t,t\) 上重新计算两路 logits，合成 \(q\)。BFN 用它构造消息并更新概率信念；DFM 用它构造跃迁速率并更新离散 token。
  3. 进入下一步，直至得到候选。新的状态再次送入两路模型，条件在整个过程中持续参与预测。最终序列再交给独立评估，检查性质响应、编辑行为与结构合理性。
固定的是模型权重，变化的是每一步预测

先验与残差都会随当前状态和时间重新输出预测；残差不是只在生成开始时加一次。下一章进一步展开图 2 中的“状态更新”：同一个干净 token 预测，如何分别驱动 BFN 的概率信念与 DFM 的离散跃迁。

From diffusion to discrete sequence generation

04 从逐步去噪，理解概率信念与离散跃迁

BFN：用贝叶斯更新积累类别信息

状态 \(\boldsymbol\theta\) 是对 \(K\) 类氨基酸的概率信念，从均匀分布出发。网络读取这些概率，预测干净 token 分布 \(q\)。

\[m\sim\mathcal{N}\!\left(a(K e_x-\mathbf{1}),\,aK I\right).\]
\[\theta'_k=\frac{\theta_k\exp(m_k)}{\sum_j\theta_j\exp(m_j)}.\]

\(e_x\) 是 token 的 one-hot 编码，\(a>0\) 控制本步信息量。训练用真实 token 构造带噪消息 \(m\)；生成时从 \(q\) 采样预测 token，再构造消息并更新信念。更新满足贝叶斯法则，下一步网络继续利用全序列上下文。

相较于直接更新带噪 token，BFN 更新的是连续取值的类别概率。

DFM：用跃迁速率更新离散 token

DFM-abs 的噪声起点是全掩码，DFM-uni 的噪声起点是均匀随机 token。下面以 DFM-abs 的线性掩码路径为例，\(t\) 从 0 走向 1，单个位点由掩码 \(M\) 逐步变为干净 token \(x\)：

\[p_t(z\mid x)=(1-t)\delta_M(z)+t\delta_x(z).\]
\[R_t(M\!\to\!k)=\frac{q(k\mid\boldsymbol{x}_t,t)}{1-t},\qquad t<1.\]

\(\delta\) 表示集中于指定 token 的分布，\(k\) 为氨基酸类别，\(q\) 预测干净 token。掩码位点在微小时间 \(\Delta t\) 内跳到 \(k\) 的概率约为 \(R_t\Delta t\)。在不含 corrector 的基础生成过程中，已揭开的位点保持不变。

DFM 用干净 token 后验构造离散跃迁，推动概率分布沿设定路径从噪声状态走向序列。

残差改变预测分布，生成框架决定如何更新

两者都能使用 \(q=\operatorname{softmax}(\ell_{\mathrm{prior}}+r_\phi)\) 作为干净 token 预测。BFN 用它产生消息并更新信念，DFM 用它构造跳变速率；第 3 章的条件残差因此可以沿用相同的分工。

A general prior for sequence generation

05 先验证基础模型在学习，再进行条件残差训练

残差方案依赖基础生成器提供可用的先验。预训练阶段先学习天然蛋白质序列的生成规律，下游阶段再冻结先验，训练性质条件对应的修正。

两条路线都出现了阶段性下降：BFN 后段仍存在波动，DFM 掩码路径在较缓的变化中继续改善。现有记录支持开展下游方法探索，但不足以声称基础模型已经充分训练。

将这样的先验用于 residual prediction，任务网络既能利用已有的序列规律，也必须面对先验覆盖不足带来的限制。后续需要区分：条件控制的不足究竟来自基础生成能力、残差容量，还是训练数据与评估协议。

loss 下降与性质控制分别检验

预训练 loss 检查基础模型对生成目标的学习；下游实验检查候选是否接近给定性质。前者改善不能替代后者，也不能直接推断新序列已经具有真实实验功能。

Residual prediction · Performance relative to the baseline

06 残差方案在哪些性质任务上带来改善？

实验聚焦 BFN 和掩码路径 DFM 的残差方案，与各自的单网络直接条件预测 baseline 比较。不同任务呈现不同幅度的变化，提升需要结合评估覆盖与编辑行为解读。

这里的 baseline 已使用蛋白质语言模型初始化，但不加载本项目的生成预训练权重；residual 则加载并冻结生成先验，再训练条件残差。该比较反映完整方案的效果，尚不能单独分离生成预训练、模型容量与残差参数化的贡献。

条件训练的验证曲线

baseline pretrain finetune residual

四条路线分别为直接条件训练（baseline）、加载生成预训练后全量训练（pretrain）、冻结骨干仅训练条件注入（finetune），以及冻结先验的残差训练（residual）。灰带表示日志中的波动范围，不代表跨随机种子的置信区间。验证 loss 反映生成目标的拟合，不等同于性质控制误差。

Method recap

07 显式分解序列先验与条件修正，改善性质控制

显式分解序列先验与条件修正的残差方案，相比对应 baseline 改善了变异效应控制，DFM 在结合性质任务上的改善更明显。

从 score 分解理解模型分工

\[s_{\mathrm{c}}=s_{\mathrm{u}}+\nabla_{x_t}\log p_t(y\mid x_t).\]

无条件项提供蛋白质序列语言，条件项提供朝目标性质调整的方向：一个模型学习什么样的序列更合理，另一个模型学习如何遵循目标条件。

在离散序列中，用残差实现这一直觉

\[\ell_{\mathrm{cond}}=\operatorname{stopgrad}(\ell_{\mathrm{prior}})+r_\phi.\]

基础模型预先学习序列规律并保持冻结，残差模型专注学习条件修正。两部分共同给出每一步的氨基酸预测，让 BFN 与 DFM 复用已有的序列语言，完成有目标的生成。
