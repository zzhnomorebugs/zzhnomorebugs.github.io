Property-driven protein design

01 给定目标性质，生成值得验证的序列

蛋白质工程希望找到具有目标功能的氨基酸序列。可控生成把目标性质直接交给生成模型，让候选提出过程具有明确方向。

  1. 输入：参考序列与目标性质参考序列提供序列上下文，目标条件描述希望达到的性质。
  2. 生成：带条件的逐步更新在序列先验的约束下，逐步调整氨基酸类别的预测。
  3. 输出：候选变体通过独立评估筛选，供后续实验验证。

生成模型需要同时处理两类要求：序列本身应当合理，生成结果也应当响应目标条件。以参考序列为起点时，还需要控制编辑幅度，避免为了追求目标性质而破坏原有序列与结构。

项目的核心问题

通用蛋白质序列先验，能否为不同性质任务提供可复用的生成基础，并通过条件适配提出具有目标倾向的候选？

目标条件表达什么？

条件可以表达变异效应、稳定性变化或结合性质。模型学习目标条件与序列变化之间的关系，而不同任务仍需要各自的标签定义和评估方法。

输出意味着什么？

输出是需要进一步验证的候选序列。模型预测的性质、结构预测的置信度和真实实验效果分别提供不同层次的证据。

Dividing the work between a general prior and task conditions

02 先学习序列规律，再学习目标条件

天然蛋白质序列提供广泛的统计规律，参考序列提供相对编辑的条件，性质标签则描述任务方向。这几类信息共同参与候选序列的生成。

无条件预训练首先学习噪声状态与真实蛋白质序列之间的关系。进入下游任务后，模型额外接收性质条件，学习在相同的生成框架下如何调整预测。

对于以参考序列为起点的编辑任务，可以把目标概括为学习条件分布：

\[p_\theta(x\mid x_{\mathrm{ref}},y).\]

其中，\(x_{\mathrm{ref}}\) 是参考序列，\(y\) 是目标性质，\(x\) 是候选序列。这一写法表达任务目标，不意味着模型已经保证每个候选都满足条件。

From conditional score decomposition to residual prediction

03 一个模型学习序列语言，一个模型学习条件遵循

从连续 diffusion 的条件控制出发，conditional score 可以分解为 unconditional score 与条件修正：前者描述序列本身的规律，后者描述目标条件带来的方向。

\[\underbrace{s_{\mathrm{c}}}_{\text{conditional score}} =\underbrace{s_{\mathrm{u}}}_{\text{unconditional score}} +\underbrace{\nabla_{x_t}\log p_t(y\mid x_t)}_{\text{条件修正}}.\]

这种分解为 CFG 提供了理解条件控制的视角，也启发了项目中两个模型的分工：

通用模型：学习蛋白质序列语言

先通过无条件预训练学习氨基酸组合与序列规律；进入下游任务后固定权重，持续提供通用生成先验。

残差模型：学习遵循目标条件

读取当前状态、参考序列和目标性质，学习需要补充的条件修正，引导候选朝目标方向变化。

在离散蛋白质序列中，两部分实际组合在 token logits 上：

\[\ell_{\mathrm{cond}} =\operatorname{stopgrad}(\ell_{\mathrm{prior}})+r_\phi.\]

训练损失作用于组合后的预测，只更新残差模型。连续 score 的分解是设计动机，实际残差并非直接计算分类器梯度。

组合预测随后交给各自的生成规则：BFN 更新氨基酸类别的概率信念，DFM 更新离散 token 序列。两者都复用固定的序列先验，由残差承担条件适配。

From diffusion to discrete sequence generation

04 从逐步去噪，理解概率信念与离散跃迁

BFN：用贝叶斯更新积累类别信息

状态 \(\boldsymbol\theta\) 是对 \(K\) 类氨基酸的概率信念，从均匀分布出发。网络读取这些概率，预测干净 token 分布 \(q\)。

\[m\sim\mathcal{N}\!\left(a(K e_x-\mathbf{1}),\,aK I\right).\]
\[\theta'_k=\frac{\theta_k\exp(m_k)}{\sum_j\theta_j\exp(m_j)}.\]

\(e_x\) 是 token 的 one-hot 编码，\(a>0\) 控制本步信息量。训练用真实 token 构造带噪消息 \(m\)；生成时从 \(q\) 采样预测 token，再构造消息并更新信念。更新满足贝叶斯法则，下一步网络继续利用全序列上下文。

相较于直接更新带噪 token，BFN 更新的是连续取值的类别概率。

DFM：用跃迁速率更新离散 token

DFM-abs 的噪声起点是全掩码，DFM-uni 的噪声起点是均匀随机 token。下面以 DFM-abs 的线性掩码路径为例，\(t\) 从 0 走向 1，单个位点由掩码 \(M\) 逐步变为干净 token \(x\)：

\[p_t(z\mid x)=(1-t)\delta_M(z)+t\delta_x(z).\]
\[R_t(M\!\to\!k)=\frac{q(k\mid\boldsymbol{x}_t,t)}{1-t},\qquad t<1.\]

\(\delta\) 表示集中于指定 token 的分布，\(k\) 为氨基酸类别，\(q\) 预测干净 token。掩码位点在微小时间 \(\Delta t\) 内跳到 \(k\) 的概率约为 \(R_t\Delta t\)。在不含 corrector 的基础生成过程中，已揭开的位点保持不变。

DFM 用干净 token 后验构造离散跃迁，推动概率分布沿设定路径从噪声状态走向序列。

残差改变预测分布，生成框架决定如何更新

两者都能使用 \(q=\operatorname{softmax}(\ell_{\mathrm{prior}}+r_\phi)\) 作为干净 token 预测。BFN 用它产生消息并更新信念，DFM 用它构造跳变速率；前一页的条件残差因此可以沿用相同的分工。

A general prior for sequence generation

05 先验证基础模型在学习，再进行条件残差训练

残差方案依赖基础生成器提供可用的先验。预训练阶段先学习天然蛋白质序列的生成规律，下游阶段再冻结先验，训练性质条件对应的修正。

两条路线都出现了阶段性下降：BFN 后段仍存在波动，DFM 掩码路径在较缓的变化中继续改善。现有记录支持开展下游方法探索，但不足以声称基础模型已经充分训练。

将这样的先验用于 residual prediction，任务网络既能利用已有的序列规律，也必须面对先验覆盖不足带来的限制。后续需要区分：条件控制的不足究竟来自基础生成能力、残差容量，还是训练数据与评估协议。

loss 下降与性质控制分别检验

预训练 loss 检查基础模型对生成目标的学习；下游实验检查候选是否接近给定性质。前者改善不能替代后者，也不能直接推断新序列已经具有真实实验功能。

Residual prediction · Performance relative to the baseline

06 残差方案在哪些性质任务上带来改善？

实验聚焦 BFN 和掩码路径 DFM 的残差方案，与各自的单网络直接条件预测 baseline 比较。不同任务呈现不同幅度的变化，提升需要结合评估覆盖与编辑行为解读。

这里的 baseline 已使用蛋白质语言模型初始化，但不加载本项目的生成预训练权重；residual 则加载并冻结生成先验，再训练条件残差。该比较反映完整方案的效果，尚不能单独分离生成预训练、模型容量与残差参数化的贡献。

条件训练的验证曲线

baseline pretrain finetune residual

四条路线分别为直接条件训练（baseline）、加载生成预训练后全量训练（pretrain）、冻结骨干仅训练条件注入（finetune），以及冻结先验的残差训练（residual）。灰带表示日志中的波动范围，不代表跨随机种子的置信区间。验证 loss 反映生成目标的拟合，不等同于性质控制误差。

Method recap

07 显式分解序列先验与条件修正，改善性质控制

显式分解序列先验与条件修正的残差方案，相比对应 baseline 改善了变异效应控制，DFM 在结合性质任务上的改善更明显。

从 score 分解理解模型分工

\[s_{\mathrm{c}}=s_{\mathrm{u}}+\nabla_{x_t}\log p_t(y\mid x_t).\]

无条件项提供蛋白质序列语言，条件项提供朝目标性质调整的方向：一个模型学习什么样的序列更合理，另一个模型学习如何遵循目标条件。

在离散序列中，用残差实现这一直觉

\[\ell_{\mathrm{cond}}=\operatorname{stopgrad}(\ell_{\mathrm{prior}})+r_\phi.\]

基础模型预先学习序列规律并保持冻结，残差模型专注学习条件修正。两部分共同给出每一步的氨基酸预测，让 BFN 与 DFM 复用已有的序列语言，完成有目标的生成。
