Entangled observations and irregular time

01 One observation can hide several sets of dynamics

A video contains multiple moving body parts; a set of trajectories contains multiple interacting objects. A sequence model often receives only their combined features, without knowing how to partition them or being able to assume evenly spaced observations.

  1. Input: timestamped joint observationsNo entity grouping is supplied for the features, and sampling intervals can vary.
  2. Learning: module dynamics and interactionsFind a useful latent division and track how modules exchange information.
  3. Output: predictions for the taskA task-specific readout predicts future trajectories, physical links, or video classes.

Entangled means no prior partition is given

The three-body experiment supplies a 9-dimensional position vector at each time, but does not tell the model which three dimensions belong to which body. Videos are first converted into features and then passed to the sequence model. “Entangled” does not require features to be reshuffled at every time.

Irregular means time intervals are not fixed

When observations are available only at some times, the model needs to use the actual timestamps rather than treat all consecutive observations as equally long steps. Continuous-time models provide a natural representation for this setting.

The central question

Can a model jointly learn which latent modules exist, how each module evolves, and how modules interact, giving complex-sequence learning a more explicit structure?

Decoupling-based Neural System

02 Model subsystem states and interaction states separately

DNS decouples dynamics in latent feature space: several subsystems each receive a control signal and maintain a hidden state, while a separate meta-system maintains their time-varying interaction weights.

First division: different controls, different states

\[x_i(t_k)=p_i\!\left(c(t_k)\right),\qquad z(t)=[z_1(t),\ldots,z_n(t)].\]

Each \(p_i\) learns a different combination of features from the same observation, producing subsystem \(i\)'s control signal \(x_i\). The number of subsystems \(n\) is a model hyperparameter and need not equal the number of physical objects.

Second division: how states change and information flows

\(z_i(t)\) describes a latent module's state; \(A(t)\) describes how information is mixed among the modules. They evolve together, rather than compressing interactions into a fixed matrix.

“Relative independence” here is a modeling preference. The subsystems remain coupled through \(A(t)\); the implementation also shares the vector-field network that updates their states, using different control signals to create a division of roles while reducing the parameter cost.

Decoupling aims for a useful latent division

The model is not required to assign each subsystem to one celestial body, one ball, or one arm. Whether such a correspondence emerges must be examined through analysis.

From discrete observations to continuous evolution

03 Connect observations and module dynamics with controlled differential equations

DNS first interpolates each subsystem's discrete control signals into a continuous path, then drives its hidden state with changes along that path. The interaction matrix determines which latent states each subsystem reads when updating.

Subsystems: control paths drive state changes

\[\mathrm{d}z_i(t)=F\!\left([A(t)z(t)]_i\right)\,\mathrm{d}x_i(t).\]

\([A(t)z(t)]_i\) is the weighted state received by subsystem \(i\). \(F\) maps it to a vector field, which is multiplied by the change in the control path \(\mathrm{d}x_i(t)\). All subsystems share \(F\), each using its own \(x_i\) and \(z_i\).

After obtaining \(x_i(t_k)\) at the observation timestamps, cubic spline interpolation provides controls and derivatives at intermediate times. For a differentiable control path, the integral form is:

\[z_i(t_1)=z_i(t_0)+\int_{t_0}^{t_1}F\!\left([A(s)z(s)]_i\right)x_i'(s)\,\mathrm{d}s.\]

The numerical solver can therefore advance in continuous time without requiring equal intervals between observations. With noisy data, natural smoothing splines can replace cubic spline interpolation of the control paths; this variant is denoted DNSS.

Meta-system: interactions remain constrained

DNS constrains each row of the interaction matrix to the probability simplex:

\[\mathcal S=\{A\in\mathbb R^{n\times n}:A\mathbf 1=\mathbf 1,\ A_{ij}\geq0\}.\]

Each row is nonnegative and sums to 1. Thus, \([Az]_i=\sum_j A_{ij}z_j\) can be interpreted as subsystem \(i\)'s weighted reading of latent states, with its own state also available to read.

A projected differential equation (ProjDE) offers a modeling perspective on constrained dynamics:

\[\dot A=\Pi_{\mathcal S}\!\left(A,g(A,z)\right).\]

For the Euclidean projection \(P_{\mathcal S}\), the directional operator is:

\[\Pi_{\mathcal S}(A,H)=\lim_{\alpha\to0^+}\frac{P_{\mathcal S}(A+\alpha H)-A}{\alpha}.\]

It describes movement along a candidate direction while respecting the feasible set. Numerical computation with finite steps requires an appropriate projection or constrained parameterization; the next chapter distinguishes two specific choices.

How does the soft version actually update interactions?

The soft version of DNS represents interactions through a logits matrix \(L\) and uses the time variation of query / key scores:

\[A(t)=\operatorname{softmax}_{\mathrm{row}}(L(t)),\qquad R(z)=\frac{Q(z)K(z)^\top}{\sqrt{d_k}}.\]
\[L(0)=R(z(0)),\qquad \dot L(t)=\frac{\mathrm{d}}{\mathrm{d}t}R(z(t)).\]

\(d_k\) is the key dimension. Euler discretization advances the latent and interaction states together; the soft version normalizes each row after updating \(L\) to obtain \(A\). In continuous time, the two are related through the chain rule:

\[\dot A=J_{\operatorname{softmax}}(L)\,\dot L.\]

This relationship explains how changes in logits propagate to interaction weights. It depends on this particular softmax parameterization and score dynamics, and does not imply that arbitrary interaction equations follow the same evolution.

Two interaction preferences on the simplex

04 Distribute information smoothly, or allow connections to reach zero?

Although both satisfy nonnegativity and normalization, softmax and sparsemax produce different interaction structures. The former maintains smooth, dense weights; the latter allows some latent connections to become exactly zero.

DNS: softmax

\[a_j=\frac{\exp(\ell_j)}{\sum_k\exp(\ell_k)}.\]

Finite logits yield strictly positive weights, suitable for adjusting information allocation continuously. Softmax can be understood through entropy-regularized optimization as smooth normalization; applying it to a probability vector generally changes that vector again.

DNSG: sparsemax

\[a=\underset{p\in\Delta}{\arg\min}\ \tfrac12\|p-\ell\|_2^2.\]

\(\Delta=\{p:p\geq0,\sum_jp_j=1\}\). This is a genuine Euclidean projection: vectors already on the simplex remain unchanged. Its output can contain exact zeros, though it may also remain dense.

Why is this projection suitable for neural networks?

sparsemax has a closed-form thresholding solution:

\[a_j=\max(\ell_j-\tau,0),\qquad \sum_j\max(\ell_j-\tau,0)=1.\]

The threshold \(\tau\) ensures normalization. The gradient also has a closed-form expression while the active set remains unchanged; changes in the active set must be handled as a piecewise differentiable mapping. It thus imposes an explicit geometric constraint while fitting into a trainable computation graph.

What perspective does Bregman divergence offer?

A “distance” can be defined through a convex function \(\phi\), rather than always using Euclidean distance:

\[D_\phi(p,q)=\phi(p)-\phi(q)-\langle\nabla\phi(q),p-q\rangle.\]

The squared norm corresponds to Euclidean geometry; negative entropy corresponds to geometry related to KL divergence. This perspective connects normalization, regularization, and projection choices, helping discuss their preferences for interaction structure. It does not mean that softmax is a Euclidean projection in logits space or that any choice has been proved to train faster.

Noisy conditions: consider projection and control paths together

With noise added during both training and testing, DNSG reaches 93.76 ± 0.36%; with noise added only at test time, it falls to 87.86 ± 0.46%. In the latter setting, DNS scores 89.56 ± 0.42%, DNSS with smoothing splines scores 92.99 ± 1.30%, and CT-GRU scores 92.80 ± 0.53%.

These results show that the benefits of sparse interactions depend on the data conditions. Smoothing the control signal can mitigate noise, and no variant can be described as better under all conditions.

The method's value and scope

07 Explicit structure reduces the burden of learning complex dynamics

DNS centers on two types of states with distinct roles: subsystems describe the evolution of latent modules, and the meta-system describes interactions among them. Continuous control paths connect irregular observations, while simplex constraints organize information flow.

The design running through the project

Learn multiple control paths from joint observations, advance different subsystems through a shared vector field, and let a time-varying interaction matrix regulate their information exchange. The soft and sparse choices bring smoothness and sparsity into this dynamic process.

  • A gap remains between latent decoupling and physical discovery. The three-body example yields a feature-level division; interaction weights are not physical forces, true adjacency, or causal relationships.
  • The number of modules must be chosen. The best number need not equal the number of objects and is selected through hyperparameter search in the experiments. The method does not automatically identify a unique true decomposition.
  • Continuous models still require numerical approximation. Interpolation or smoothing of control paths, the Euler step size, and noise conditions all affect practical behavior.
  • The experimental conclusions have a defined scope. The three benchmarks support this structure's value on the tested tasks; they do not prove optimality for every complex system or guarantee physical conservation or stable long-term prediction.

This work offers a reusable idea: when a joint sequence is difficult to model directly, express module dynamics and interaction dynamics separately, then use both task outcomes and structural analysis to test whether the decomposition is effective.
